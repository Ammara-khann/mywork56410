# DevOps Practice Repo

Starter files for the practice midterm.

| File | Purpose |
|------|---------|
| `app.py` | Small Flask app with a Redis hit counter |
| `requirements.txt` | Python dependencies |
| `access.log` | Sample web log for Linux command practice |
| `EXAM_PAPER.md` | The practice paper. Start here. |

## How to practice

1. Pre-pull images first (at home, on good internet):
   ```
   docker pull python:3.11-slim
   docker pull redis:alpine
   ```
2. Set a 60-minute timer and open `EXAM_PAPER.md`.
3. Do NOT look at notes first. Only use them if you get stuck.
4. Note which tasks took more than a few minutes. Practice those again.
5. Tell your teacher which task went wrong and paste the error.
